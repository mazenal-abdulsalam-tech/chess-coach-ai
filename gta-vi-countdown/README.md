# VI Countdown

A self-contained, responsive GTA VI fan countdown dashboard with a neon Vice City-inspired look.

## Run it
Open `index.html` in a browser. No build step or dependencies are required.

## Publish with GitHub Pages
1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose **main** and the **/ (root)** folder for the repository root, or use a Pages configuration that publishes this folder if your account's Pages settings support it.
5. Save and wait for GitHub Pages to publish.

The site files live in `gta-vi-countdown/`. If Pages is configured to publish the repository root, either move/copy these files to the root or use a dedicated Pages workflow to publish this folder.

## Features
- Live countdown with days/hours/minutes/seconds and alternate unit modes
- Custom target date, saved locally in the browser
- Full-screen mode and share action
- Searchable 100+ item feature roadmap
- Responsive layout and reduced-motion support
